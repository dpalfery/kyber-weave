# conductor skills

## Skills

Use the `delivery-execution` skill for the worker pool, the review ladder and the findings
collection. Use `task-gate` when a worker reports a gate failure it cannot resolve.

## Documents

Read only the plan or specification, its task file, and the todo folder. Discovery of code
or configuration is the worker's job, not the conductor's.
