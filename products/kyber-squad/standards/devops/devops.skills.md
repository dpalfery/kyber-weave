# devops skills

## Platforms

Use the platform folder's rules and skills for the platform the task names: `github`,
`azure-devops`, `gitlab` or `jira`.

## Tools

Use the platform's CLI and its own documentation. Confirm a permission or trigger name
against the platform's current reference when the behaviour is version-sensitive.
