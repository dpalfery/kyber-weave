# csharp skills

## What this folder covers

- Clean Architecture placement and project boundaries.
- ASP.NET Core Web API surface: controllers, `TypedResults`, DTOs.
- File upload handling and size limits.
- OpenTelemetry instrumentation for requests and dependencies.
- Backend-for-frontend with YARP.
- Azure AI and retrieval-augmented patterns.
- The build and test command reference.

## Library documentation

Confirm the current API of any library you configure against its own documentation, and
follow the versions the standard pins. Do not rely on memory for a library's surface.

## Hand-off

When another technology is involved, report its input as an open item naming the table and
columns (data access), the endpoint contract (client UI), or the pipeline command
(delivery).
