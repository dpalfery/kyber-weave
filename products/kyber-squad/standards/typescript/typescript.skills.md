# typescript skills

## What this folder covers

- Strict types at boundaries and honest absent values.
- Data access without N+1 or unbounded reads.
- Error and async lifecycle.
- ESM conventions and the typecheck, lint, build and test commands.
- Library documentation for any package you configure.

## Hand-off

When ceding work to delivery, provide the Node version, install, build and test commands,
and any native dependency.
