# data-access-layer skills

## Database tooling

- Confirm the current API of `Microsoft.Data.SqlClient` and FluentMigrator before use.
- How a test obtains a database, creates the schema and cleans it up is the test standard's
  answer; this folder does not invent a second one.

## Hand-off

Report a schema need as an open item with the table definition block, not as an unapproved
migration.
