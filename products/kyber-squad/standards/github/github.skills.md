# github skills

## GitHub CLI

Use `gh` for runs, pull requests, releases and workflow inspection. Confirm a verb's flags
with `gh <verb> --help` before a scripted use.

## GitHub Actions

Use the `github-actions` standard for workflow shape, naming, permissions and caching. It is
the policy; this folder is how the work is done.

## Deployment

Agree the stack output names with the infrastructure code before a deployment step consumes
them.
