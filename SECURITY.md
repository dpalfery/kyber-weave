# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main`. Older releases may
not receive backports.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately using GitHub Security Advisories:

1. Open [https://github.com/dpalfery/kyber-weave/security/advisories/new](https://github.com/dpalfery/kyber-weave/security/advisories/new)
2. Include steps to reproduce, impact, and any suggested fix
3. We will acknowledge the report and coordinate disclosure

Thank you for helping keep Kyber-Weave and its users safe.
